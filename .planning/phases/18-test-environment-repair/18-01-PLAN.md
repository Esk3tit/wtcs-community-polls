<objective>
Fix the missing `[auth.email]` section in `supabase/config.toml` so the local gotrue container accepts email/password sign-in from integration test fixture users.

Purpose: The root cause of `email_provider_disabled` is that the absent `[auth.email]` TOML section causes the CLI Go struct `email.EnableSignup` to default to `false`, passing `GOTRUE_EXTERNAL_EMAIL_ENABLED=false` to the gotrue container at boot. Adding `enable_signup = true` and `enable_confirmations = false` corrects the env var at the next `supabase stop && supabase start`.

Output: A patched `supabase/config.toml` and confirmation that `vote-counts-rls.test.ts` reports 12 PASS / 0 FAIL after a local stack restart.
</objective>
