<objective>
Restore two semantic `<h2>` headings in `AdminsList` and `CategoriesList` that were demoted to non-semantic `<div>` CardTitle elements with ARIA workarounds (`role="heading" aria-level={2}`) during Phase 17.

The fix has three steps:
1. Add `asChild` polymorphism to `CardTitle` in `src/components/ui/card.tsx` using `Slot.Root` from `radix-ui` (exact same pattern as `button.tsx` and `badge.tsx`).
2. Replace the ARIA-workaround call sites in `AdminsList` and `CategoriesList` with `<CardTitle asChild><h2>…</h2></CardTitle>`.
3. Update the stale ARIA-workaround explanation comments in the two component unit test files (no assertion changes — tests already use `getByRole('heading', { level: 2 })`).

Purpose: Satisfy UIDN-06 — restore native heading semantics without regressing shadcn Card structure. Visual rendering is identical before and after.
Output: Updated card.tsx, AdminsList.tsx, CategoriesList.tsx, admins-tab.test.tsx, categories-tab.test.tsx.
</objective>
